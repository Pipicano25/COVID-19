# COVID-19

Página web estática que presenta información sobre variantes de COVID-19 mediante un carrusel de imágenes. Es un ejercicio sencillo de maquetación web con Bootstrap, con navegación básica entre dos páginas.

## Tecnologías

- HTML
- CSS
- Bootstrap 4

## Uso

Abrir `index.html` en un navegador. La página principal muestra un carrusel con imágenes de las variantes y un enlace a `index2.html`.

## Estructura

- `index.html` — página principal con carrusel de imágenes.
- `index2.html` — página secundaria.
- `css/css.css` — estilos propios.
- `img/` — imágenes de las variantes.
